How an appeal is decided

Record
moderator, rule, action and the SHA-256 of the content
Appeal
the affected user, within 7 days, pays the bond and submits the content (hash must match)
Validators judge
which rules of the written policy the content violates
Validators agree if
all find a violation, or all find none
None violated
overturned: bond back plus the reward
Any rule
upheld: the bond goes to the community pool
Pool
every action reserves one reward; no reward, no moderation
Create a community
  1. 01Policy

    The community writes numbered rules, sets an appeal bond and an overturn reward, and funds the pool that pays for its mistakes.

  2. 02Action

    A moderator records who, which rule, what action and the content hash. One reward is reserved for as long as the action can be appealed.

  3. 03Appeal

    The user submits the content and their side. Validators read it against the policy; if nothing is violated, the user is paid for the moderator's mistake.
